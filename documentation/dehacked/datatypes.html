Data Types

There are three data types you will encounter when working in DeHackEd. Strings (str), Integers (int), Unsigned Integers (uint), and Fixed-Point Numbers (fixed). Strings are for text, such as when defining a name or cheat code. Integers are for positive and negative whole numbers, such as ID's or health. Unsigned integers are only 0 and positive whole numbers, such as DeHackEd numbers or thing states. Fixed-point numbers are for decimals, such as pitch or angle.

The key difference between integers and fixed-point numbers is that a fixed-point number is a representation of a fractional number as an integer. This is done by multiplying the decimal value by a known multiplication factor. For example, if we have a known multiplication factor of 100, then the decimal of 3.14 would have a fixed point representation of 314.

Doom uses a fixed point number system as a means of efficiency. Internally, fixed point numbers are stored as a 32 bit integer in 16.16 format. The first 16 digits define the integer, whilst the latter 16 digits are the decimal stored as a fraction. In binary, each digit is 2n; where the rightmost digit is 20 and the 17th digit, where our integer now resides, is 216. Therefore, if we want to convert any number into a fixed-point number for DeHackEd, we need to multiply it by 216, or 65536.

For example, the number 1.5 would become 98304.

Some decimal numbers are impossible to store as fixed-point values. 0.1 becomes 6553.6, but our fixed-point value needs to be a whole number. Therefore, the closest numbers to 0.1 that can be represented as fixed-point values are 0.0999908447265625 and 0.100006103515625; or 6553 or 6554 respectively.
